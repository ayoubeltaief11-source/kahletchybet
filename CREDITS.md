# CREDITS AND LICENSES

kahlatchybet is an educational casino simulator. The virtual unit TD has no
monetary value. There are no deposits, withdrawals, payment integrations, or
real-money links anywhere in this project.

## Audio

All sound effects and ambient beds are synthesized at runtime with the raw
Web Audio API using oscillators, noise buffers, and envelopes.
No audio files are downloaded, bundled, or streamed. No third-party audio
license is required.

## Cover images

Covers are generated as original SVG by the imageLoader fallback.
Any raster cover placed in public/assets/GAME_ID/ is produced by the project
owner with a free image generator and must be original artwork.

## Originality policy

Game names, characters, palettes, and layouts are original to this project.
Game mechanics and quality benchmarks are inspired by publicly observable
industry standards. No trademarked name, logo, character, or artwork is
reproduced. Reference titles are used only internally as quality targets and
never appear in the product.
